01 · Overview

From Packet Capture to Incident Report

This project demonstrates the core stages of a lightweight SOC investigation, from reconnaissance to packet analysis and incident documentation.

🎯

Objective

Detect network reconnaissance and identify port-scanning behavior from captured network traffic.

🧰

Tools Used

Nmap for reconnaissance, Wireshark for packet inspection, and TCP/IP networking concepts for analysis.

🌐

Environment

A local network security lab used to simulate and investigate reconnaissance activity.

02 · Investigation

Attack Simulation & Traffic Analysis

The investigation correlates the reconnaissance command with packet-level evidence captured during the lab.

⚡ Reconnaissance Command


nmap -sS -A 192.168.1.37

This performs a TCP SYN scan together with service and operating-system detection.

📡 Wireshark Filter


tcp.flags.syn == 1 && tcp.flags.ack == 0

This filter isolates TCP SYN packets without an ACK, helping identify scanning activity.

🧠 Analyst Conclusion


Multiple SYN packets were observed against different ports without completing the TCP handshake. This behavior matches a TCP SYN scan and is characteristic of the reconnaissance phase of a cyber attack.
